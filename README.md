# Strata-HotRod: legacy (solid.cpp and the 18 Nov 2026 write-up)

This branch keeps, for the record, the work that came before the current engine. It is not maintained; the engine is on
[`main`](https://github.com/sangharshadhyeta/Strata-HotRod).

| Path | What it is |
|---|---|
| `index.html` | The illustrated write-up (an animated page: how experts are placed, what solid.cpp found, how each lesson became part of HotRod, results). Open it in a browser from a local copy. |
| `print/technical-note.html` | The formal print copy of the write-up, with the references. |
| `assets/` | Pictures used by the two pages. |
| `solid-cpp/` | **solid.cpp**, the learning ground (August to October 2026): the changed sources of a llama.cpp fork with an MoE expert cache, and the notes that record what worked and what did not (`docs/`, `ROADMAP`, `LEARNINGS`). Not a buildable copy: the base is llama.cpp commit `1f368f354` (13 August 2026). |
| `CITATIONS.md` | Every project, paper, model, dataset and person credited. |
| `UPSTREAM.md` | What is whose. |
