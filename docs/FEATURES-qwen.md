## How to use a switch

- Environment switch: put `"NAME": "value"` into the model config's `"env"` object. A blank value means the engine's default; the server drops it.
- Engine flag: put `"--name"` and its value (if it takes one) into the model config's `"args"` list.
- Server key: put `"key": value` at the top level of the model config.

Reading the tables:

- **Default**: the value written literally on the use's line (a ternary fallback, or a literal default argument). `unset` means the line only tests whether the variable is set or null, so the value when unset is whatever that test selects; read the comment. `see code` means no literal default is on that line.
