# solid.cpp (the learning ground)

An earlier, separate project (August to October 2026): a fork of [llama.cpp](https://github.com/ggml-org/llama.cpp) with an
MoE expert cache, stand-in experts and a measured, paired A/B method. This folder holds only the files that were written or
changed for it; everything else in that project is llama.cpp's own and is not copied here. See `LICENSE-llama.cpp`.

What it taught, and how each lesson became part of HotRod, is on the main page: [`../index.html`](../index.html).
The working notes behind it are in `docs/` (`moe-cache-colibri-notes.md`, `ROADMAP.md`, `LEARNINGS.md`, `plan.md`).
